# Experiments

실제 서비스 코드와 독립적으로 실행하는 연구·학습·비교 실험을 보관합니다.

- [`beginner_pipeline/`](beginner_pipeline/README.md): 합성 특징 데이터와 로지스틱 회귀 모델을 사용하는 독립형 학습·평가 예제. 모델 코드·가중치·학습·평가·테스트·reference 코드 포함.

검증한 실험을 서비스에 반영할 때에는 `services/ai/`에 옮기고 해당 서비스의 테스트와 문서를 함께 갱신합니다. 현재 실시간 서비스는 이 실험의 합성 분류 모델을 사용하지 않습니다.
